> **Historical decision — superseded by [2026-09-23-review-and-validation-gates](2026-09-23-review-and-validation-gates.md).**
> The original record below is preserved as history, not current guidance.
> Consult `PROTOCOL.md` and the new ADR for adopted scope and unresolved hypotheses.


**Context**: Reward and floor amounts must be bit-identical between the Rust
on-chain contract and the TypeScript client, which floating point cannot
guarantee across platforms and compilers.

**Decision**: All emission arithmetic — block decay, pari-mutuel split,
weighting, reserve and floor — uses Q64.64 fixed point, validated against
one shared set of cross-language vectors (`#V5`, extended in `#PC4`).

**Consequences**: Any new math primitive must be implemented in Q64.64 in
both languages before it ships, with a vector added. No exceptions for
"it's only a display calculation".
