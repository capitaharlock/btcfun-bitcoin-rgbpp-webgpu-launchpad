## Execution

- Phase: 4.
- Prerequisites: `PC7`, `SH4`, `PV3`.

## Done when

- Reviewer scope includes xUDT authority, reserve custody, membership completeness, proof handling and cross-chain assumptions.
- Findings have severity, reproducible cases and documented resolution or explicit launch-blocking status.
- Review applies to exact source/dependency revisions and reproducible deployment binaries; material changes trigger focused re-review.
