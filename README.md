# btc.fun

**Community token launches with verifiable mining and transparent reserves.**

A specification-stage project exploring Bitcoin-scheduled issuance, RGB++
ownership, Nervos CKB settlement and browser proof-of-work. The goal is both a
reproducible demonstration of technical depth and a product communities want to
use repeatedly.

**Status: spec-only; economic and architectural validation comes first.**
The initial reserve model failed review. Its replacement is a hypothesis to
validate, not a promise of capital protection or a guaranteed rising floor.

First demo: one launch, one real wallet, one CKB-side reserve asset, mining,
settlement, redemption, independent verification and operator-free recovery.
Automatic graduation and a marketplace follow only after validation.

Project management follows the [MeshKore standard](https://meshkore.com/standard).
